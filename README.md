# NOW Network

**The Live Reality Network**

NOW turns stale physical-world information into refreshable state.

A user can fund a refresh, a nearby contributor can submit request-bound mobile evidence, and the updated state can be settled through Solana.

## Core loop

`ASK / REFRESH → PROVE → KNOW → PAY`

## Repository layout

- `apps/android` — Android client
- `backend` — API and control-plane code
- `programs/now-settlement` — Solana settlement program
- `packages` — shared contracts and domain code
- `supabase` — Supabase functions and configuration
- `tests` — integration and end-to-end tests
- `scripts` — build and release utilities

The project is under active development.
